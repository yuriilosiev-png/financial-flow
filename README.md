# Финансовый поток

Учёт доходов, расходов и времени по видам деятельности: сколько приносит каждое направление в час,
где поднять цену, что усилить, от чего отказаться.

## Устройство (как у Планера)

- `index.html` — всё приложение (HTML/CSS/JS), отдаётся с GitHub Pages:
  `https://yuriilosiev-png.github.io/financial-flow/`
- `app/` — Android-обёртка (WebView). Без сети открывается офлайн-копия `index.html`,
  которую CI кладёт в `assets` при сборке. Данные — в localStorage на телефоне.
- `.github/workflows/build-apk.yml` — сборка в GitHub Actions:
  - **тестовый APK** — всегда, подписан `app/test.jks` (открытые пароли, только для теста,
    ставится поверх прошлой версии без потери данных);
  - **AAB для Google Play** — только когда в Secrets заданы `KEYSTORE_BASE64`, `KEY_ALIAS`,
    `KEY_PASSWORD`, `STORE_PASSWORD`.

## Этапы

1. ✅ Потоки и работы, «Отметить работы», ручной ввод расходов и доходов, расходы по группам,
   анализ ₾/час и советы по цене, резервная копия.
2. Подписки и регулярные платежи, тренды по времени и материалу.
3. SMS банков (TBC, Банк Грузии): личная сборка с чтением истории, версия для Play — через уведомления.
4. Облако (Firebase) и восстановление.
5. Подготовка к Play: политика конфиденциальности, Data safety, языки.
